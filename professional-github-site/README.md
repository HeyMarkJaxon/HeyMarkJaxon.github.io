# Professional Portfolio — GitHub Pages Starter

A clean static portfolio designed for an early-career cybersecurity professional moving toward Identity & Access Management, Microsoft 365, cloud infrastructure security, and enterprise technology.

## Before publishing

Open `index.html` and replace these placeholders:

- `YOUR NAME`
- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`
- The single-letter brand mark `M` if desired

Search the entire repository for `YOUR_` to make sure nothing is missed.

## Publish with GitHub Pages

1. Create a repository named `YOUR_GITHUB.github.io`.
2. Upload the files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, publish from the branch containing these files (typically `main`) and use `/ (root)` as the folder.
5. Once deployed, your default address will be `https://YOUR_GITHUB.github.io`.

## Custom domain

Do **not** rename `CNAME.example` to `CNAME` until you have inserted the exact custom domain you want GitHub Pages to serve.

See `DOMAIN_SETUP.md` for the DNS and GitHub steps.

## Content rule

Do not publish CTF flags, challenge answer keys, credentials, private IP details tied to active environments, proprietary screenshots, or any employer/customer data. Describe your process and reasoning instead.
